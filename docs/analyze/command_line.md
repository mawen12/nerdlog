# Command Line

## cmdline

由 `cmd/nerdlog/cmdline.go` 负责

## 命令

| 命令         | 描述                       |
| ------------ | -------------------------- |
| `h`          | 输出帮助信息               |
| `help`       | 输出帮助信息               |
| `time`       | 设置 --time                |
| `w`          | 写入日志文件               |
| `write`      | 写入日志文件               |
| `set`        | 设置选项                   |
| `xc`         | 复制到剪贴板               |
| `xclip`      | 复制到剪贴板               |
| `nerdlog`    | 回到出厂设置               |
| `prev`       | 历史导航向前               |
| `bac`        | 历史导航向前               |
| `bck`        | 历史导航向前               |
| `back`       | 历史导航向前               |
| `next`       | 历史导航向后               |
| `fwd`        | 历史导航向后               |
| `forward`    | 历史导航向后               |
| `e`          | 打开编辑页面               |
| `edit`       | 打开编辑页面               |
| `q`          | 退出应用                   |
| `quit`       | 退出应用                   |
| `reconnect`  | 重新连接                   |
| `disconnect` | 断开连接                   |
| `refresh`    | 刷新                       |
| `conndebug`  | 显示连接调试信息           |
| `cdebug`     | 显示连接调试信息           |
| `querydebug` | 显示最后一次查询的调试信息 |
| `qdebug`     | 显示最后一次查询的调试信息 |
| `debug`      | 显示最后一次查询的调试信息 |
| `version`    | 显示版本信息               |
| `about`      | 显示版本信息               |
