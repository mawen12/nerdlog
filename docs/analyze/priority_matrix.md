# Nerdlog 功能优先级分析

## 🎯 优先级体系

| 等级 | 标记        | 定义                         | 示例               |
| ---- | ----------- | ---------------------------- | ------------------ |
| P0   | 🔴 CRITICAL | 没有这个功能应用无法运行     | 日志查询、远程连接 |
| P1   | 🟠 HIGH     | 重要功能，没有会极大降低体验 | 历史记录、导航     |
| P2   | 🟡 MEDIUM   | 有用的功能，增强用户体验     | 字段编辑、索引     |
| P3   | 🟢 LOW      | 锦上添花的功能               | 颜色、版本显示     |

## 🔍 功能间的相互影响

### P0 功能影响范围

```
C1 日志查询执行
  └─► 影响: C2, C4, C5, C7 (其他Core功能)
  └─► 影响: T3, T4 (Transport功能)
  └─► 影响: U1, U2 (显示功能)
  └─► 影响: H1, H2 (历史功能)

U1 日志表显示
  └─► 依赖: C1, C2, C3 (查询功能)
  └─► 影响: U7, ADV1-ADV3 (显示增强)

T1 SSH连接
  └─► 影响: T2, T3, T4, T5 (所有Transport功能)
  └─► 影响: C1-C7 (所有查询功能)
```

H1 命令行历史
