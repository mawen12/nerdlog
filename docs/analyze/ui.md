# UI

## tview

`UI` 主要使用 `tview` 进行展示。其核心类就是 `MainView`。

- `screenWidth` 屏幕宽度
- `screenHeight` 屏幕高度
- `rootPages` 根页面
- `logsTable` 日志表
- `queryLabel` 查询 label
- `queryInput` 查询输入框
- `cmdInput` cmd 输入框
- `topFlex`
- `queryEditBtn` 查询按钮
- `timeLabel` time label
- `menuDropdown` 页面的 menu 是一个 dropdown 组件
- `queryEditView` 查询编辑视图
