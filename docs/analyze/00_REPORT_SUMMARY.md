```
  │    │    └─ nerdlog_agent.sh
  │    │
  │    └─► Transport
  │         ├─ SSHTransport
  │         ├─ LocalTransport
  │         └─ CustomCmdTransport
  │
  ├─► Config (logstreams.yaml)
  ├─► Logger (日志)
  └─► History (历史)
```

```
强 (必须): UI → Core, Core → Transport, Transport → Remote
```
